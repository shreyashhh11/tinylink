LOCAL SETUP INSTRUCTIONS:
==========================
1. Backend Setup:
   cd backend
   npm install
   cp .env.example .env
   # Update .env with your database URL
   npx prisma generate
   npm run migrate:dev
   npm run dev

2. Frontend Setup:
   cd frontend
   npm install
   npm run dev

3. Access:
   Frontend: http://localhost:3000
   Backend: http://localhost:3001
   Health Check: http://localhost:3001/healthz
